# 社区养老服务管家 · UI 设计规范 v2.0

**风格定位：温润流光 · 灵动康养（Soft Organic Care）**
专为“子女远程尽孝 + 社区贴心管家 + 长辈安心使用”打造的现代适老视觉系统。告别传统B端后台和政府政务风的“方方正正、生硬死板”，以**有机流线、温润大曲率（Squircle）、非对称呼吸排版、直觉式一键交互**为核心。

## 1. 核心设计原则（三大支柱）

1. **简约大气（留白与主次）**：一屏只聚焦一个核心意图。去边框化设计（Borderless），用柔和的明暗温差与弥散光影替代生硬的 `1px` 实线分割。
2. **灵动不呆板（流体与有机形态）**：
   - 打破“3×2 豆腐块网格”：采用 **1主（陪诊大横卡）+ 2中（保洁/适老化双翼卡）+ 胶囊快选流（代办/助餐/紧急）** 的灵动错落布局（Organic Bento）。
   - 采用非对称有机圆角（如 `40rpx 40rpx 56rpx 24rpx`）与 40rpx–48rpx 超大鹅卵石圆角。
   - 背景融入柔和的有机流体光斑（Organic Aura Blobs），让画面有呼吸感与生命力。
3. **操作极简便捷（直觉式一触即达）**：
   - **告别层层下拉框**：下单页の長辈选择、服务切换、常用日期、时间段全部改为**横向灵动胶囊/卡片直接点选**，减少 70% 的弹窗操作。
   - **登录页一键体验**：提供“家属体验号 / 管家员工号”一键填入并登录胶囊，测试与演示零门槛。
   - **悬浮灵动操作岛（Floating Island Bar）**：底部操作栏采用离底悬浮的大圆角毛玻璃胶囊岛，视觉轻盈且拇指极易触达。

## 3. 形体与光影（告别方正）

- **大曲率圆角**：
  - 英雄区/顶部流体弧线：`0 0 64rpx 64rpx` 或悬浮大卡 `48rpx`
  - 主容器卡片：`40rpx`（无硬边框，纯靠光影托起）
  - 灵动错落卡：`36rpx 36rpx 48rpx 28rpx`（微非对称有机感）
  - 胶囊与主按钮：`999rpx`（全圆润鹅卵石手感）
- **弥散柔光影（Ambient Shadow）**：
  - 浮岛阴影：`0 20rpx 50rpx -12rpx rgba(22, 74, 51, 0.07), 0 4rpx 16rpx rgba(22, 74, 51, 0.03)`
  - 主按钮发光阴影：`0 16rpx 36rpx -6rpx rgba(31, 99, 69, 0.28)`
  - 暖橙发光阴影：`0 16rpx 36rpx -6rpx rgba(232, 122, 72, 0.28)`

## 4. 核心页面灵动升级要点

1. **登录页**：顶部流体光影画布 + 悬浮层叠玻璃感登录岛 + 底部“一键切换家属/员工账号”胶囊。
2. **首页**：
   - 顶部流体弧形背景与悬浮问候岛，状态指示带呼吸绿点。
   - **灵动服务矩阵**：首推“安心陪诊”全宽带弧度大卡（含服务亮点标签与一键预约按钮）+ “居家保洁 / 适老化评估”双翼灵动卡 + “代办跑腿 / 助餐配送 / 紧急联系”轻巧胶囊流。
   - **管家悬浮名片**：圆润双色融合卡，右侧一键拨号脉冲圆钮。
3. **预约下单页（极致便捷）**：
   - 长辈选择：横向头像胶囊一键点选（不再弹原生滚轮）。
   - 服务选择：灵动价格卡片一键切换。
   - 时间选择：内置“明天、后天、三天后”快捷胶囊 + “上午 09:00 / 10:00 / 下午 14:30”一键时段胶囊，同时保留自定义日历兜底。
   - 底部离地悬浮胶囊操作岛：左侧动态价格、右侧大圆角立即预约。
4. **订单详情与员工工作台**：
   - 顶部流光状态卡 + 悬浮胶囊进度条（带发光当前节点）。
   - 底部悬浮毛玻璃操作岛。
5. **管理后台（Web）**：
   - 左侧深林绿悬浮圆角导航栏（脱离死板的直角贴边，采用内嵌圆角浮岛侧栏）+ 右侧大圆角无边框感数据卡片。

## 5. 列表页头部布局规则

- 页头有操作按钮时，**标题独占一行，按钮另起一行等分排列**；不要把标题和两个按钮硬塞在同一行，否则窄屏会把标题挤成竖排。
- 主按钮放右侧或下方，次按钮用浅底；两个以上按钮用等宽胶囊。
- 列表卡片与页头之间保留 24rpx 呼吸间距，避免拥挤。

## 6. TabBar 图标规范

- 尺寸：96×96 PNG（微信建议 81×81，96 在高分屏更清晰），单张 <40KB；
- 普通态：`#8C9690` 线性图标，透明底；
- 选中态：`#1F6345` 绿色圆角块 + 白色实心图形，配合 `selectedColor: #1F6345` 文字；
- 结构：首页（房子）、订单（服务单据）、我的（人形）；
- 原生 tabBar 不支持滑动胶囊动画；选中反馈靠“绿底白图标 + 绿色文字 + 白色 tabBar 背景”实现。如果后续要“胶囊滑动”效果，再上 custom-tab-bar。
- 资源目录：`apps/miniapp/assets/tabbar/`，app.json 中分别配置 `iconPath` 与 `selectedIconPath`。


## 7. 订单号展示规则

- 详情页必须展示订单号，但作为**弱化小字**，放在标题/状态卡附近，支持点击复制；
- 列表页、首页不突出订单号，避免干扰服务识别；
- 员工端靠“服务 + 长辈 + 时间 + 地址”识别订单，订单号用于售后、对账、客服定位。
